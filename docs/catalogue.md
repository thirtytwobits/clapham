# Catalogue

Every composed set provides bounded discovery and version operations. Describe returns
selected descriptors admitted by required scopes and current host policy, in name order.
Named discovery treats unknown, unselected and denied names as `unknown_operation`.

Discovery checks are repeatable and must not consume approvals or dispatch effects. Typed
resource policies run on invocation because they require the requested resource input.
Selections and definition revisions identify exposed contracts; calls recheck permissions.

MCP discovery derives tools/resources from the admitted catalogue and applies finite paging
and byte limits. CLI discovery builds commands from the authenticated service's catalogue.
See [the contract](contract.md) and [composition reference](composition.md).
