# Workspace guide

Clapham has five library crates. `clapham` owns transport-independent operations and shared
configuration. `clapham-cli` derives the authenticated command line. The MCP server/client
crates adapt operations through rmcp. `clapham-conformance` supplies differential fixtures.

Start with [composing an application](composing.md), [the contract](contract.md),
[composition](composition.md), [calls](calls.md), [CLI](cli.md), [MCP](mcp.md) and
[conformance](conformance.md). All libraries require Rust 1.88; gates use Rust 1.99.0.

Run `cargo xtask check`, `cargo xtask boundaries` and `cargo xtask api` for repository
validation. Schemas and public API snapshots are generated by their gates. Both the pure
Rust typed example and JSON-plus-Rust lists example build with Cargo alone.
