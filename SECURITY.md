# Security policy

Report vulnerabilities privately through
[GitHub's advisory form](https://github.com/thirtytwobits/clapham/security/advisories/new).
Private vulnerability reporting is enabled for this repository. Please do not disclose
unfixed vulnerabilities in public issues or pull requests.

Include the affected tag or commit, crate and feature set, a minimal reproducer, the observed
impact and any proposed mitigation. Avoid including credentials or private application data.
Maintainers will assess the report and coordinate a fix and disclosure through the private
advisory. No response deadline is promised.

Clapham is preparing its initial release candidate. Security fixes target the latest release
and `main`; earlier prereleases are superseded. Upgrade to the current fixed tag when one is
available. `release.json` records the security contact alongside each release's metadata.
